🌐 HTML5 (HyperText Markup Language) Complete Notes

HTML forms the structural foundation of every webpage. Below are core concepts and key semantic elements:

Core Concepts:

  • Tags & Elements: HTML tags open with <tag> and close with </tag>.
  • Attributes: Provide additional element information (e.g., class, id, src, href).

Important Semantic Elements:

  • <header>: Top container for branding, page titles, and primary navigation.
  • <nav>: Encloses major site navigation links.
  • <main>: Contains the primary, unique content of the page.
  • <section>: Groups related thematic content together.
  • <article>: Self-contained, independent content block (e.g., blog post).
  • <aside>: Secondary sidebar content or related links.
  • <footer>: Bottom section for copyright statements and metadata.

🎨 CSS3 (Cascading Style Sheets) Complete Notes

CSS controls visual presentation, styling, and responsive layout designs:

Key Styling Concepts:

  • Selectors: Element selectors (h1), Class selectors (.class), and ID selectors (#id).
  • Box Model: Concept defining Margin, Border, Padding, and Content area dimensions.

Layout Systems:

  • Flexbox: Ideal for 1-Dimensional alignment (e.g., display: flex; justify-content: center; align-items: center;).
  • CSS Grid: Optimal for 2-Dimensional grid layouts (e.g., display: grid; grid-template-columns: repeat(3, 1fr);).
  • Media Queries: Enables responsive mobile breakpoints: @media (max-width: 768px) { ... }.

🌱 Git & GitHub Version Control Guide

Comprehensive workflow guide for tracking code changes, saving versions, and hosting projects:

Git vs GitHub:

  • Git: Distributed Version Control System tracking local project changes.
  • GitHub: Cloud-based platform hosting Git repositories online for remote access.

Essential Git Terminal Commands:

git init - Initializes a new local Git repository.

git status - Displays working tree status and modified files.

git add . - Stages all modified files for the next commit.

git commit -m "Message" - Saves staged changes to repository history.

git branch -M main - Renames default active branch to 'main'.

git remote add origin [URL] - Links local repository to remote GitHub repository.

git push -u origin main - Uploads local commits to the remote GitHub main branch.

git pull origin main - Fetches and merges latest remote updates into local branch.

🚀 Beginner Practice Project Ideas

Want to test your HTML & CSS skills? Try building these beginner-friendly projects:

  • 1. Personal Profile Card: A clean card featuring your photo, short bio, social links, and a follow button. (Focus: Box model, Flexbox).
  • 2. Product Landing Page: A simple page for a product (like headphones or shoes) with an image, description, and a "Buy Now" CTA button. (Focus: Grid/Flexbox layouts).
  • 3. Simple Recipe Blog: A single-page recipe layout featuring ingredients list, step-by-step instructions, and nice typography. (Focus: Semantic HTML elements).

💡 Starter HTML5 Boilerplate

Standard foundation template required for starting any new web development project:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document Title</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <header>
        <h1>Welcome to My Website</h1>
    </header>
    <main>
        <p>Main content goes here...</p>
    </main>
    <footer>
        <p>&copy; 2026 DevLearn</p>
    </footer>
</body>
</html>
